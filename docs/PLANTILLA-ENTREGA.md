# Formato de entrega

```text
Cambio OpenSpec: [ID y ruta real]
Revisión aprobada: [referencia inequívoca]
Tarea en tasks.md: [número e ID estable]
Requisitos aplicables: [rutas y secciones]
ID / estado: T01 / [listo para revisión, bloqueado o terminado]
Goal: [resultado observable acordado]
Aceptación: [criterios y evidencias]
Sesiones / worktrees: [identificadores reales o no disponibles]
Modelo / esfuerzo: [solicitados] / [observados o no observables]
Skills aplicadas: [nombres y rutas reales]
Cambios: [archivos y resumen del diff]
Verificación: [comandos, resultados y alcance; o no ejecutado + motivo]
Integración / dependencias: [comprobadas o pendientes]
Riesgos o bloqueos: [detalle o ninguno identificado]
Commit de la tarea: [hash real, o pendiente + motivo]
Consumo: [dato observado y alcance, o no disponible]
Estado en tasks.md: [actualizado por Astra o pendiente con motivo]
Cierre del cambio: [no procede, pendiente o ruta real archivada]
```

No declarar verificaciones ni hashes que no estén observados.
